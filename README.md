#  Vendor Performance Analysis

## Overview
This project analyzes vendor performance using Python, SQL, and Power BI to help identify high-performing vendors, purchasing trends, inventory patterns, and sales performance.

## Objectives
- Analyze vendor purchasing behavior
- Evaluate sales performance
- Monitor inventory movement
- Identify top-performing vendors
- Generate interactive business insights using Power BI

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- SQL
- Power BI
- CSV Datasets
